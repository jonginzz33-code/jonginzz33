# 광고알림 차단 (Android)

폰에 오는 광고 푸시를 **도착 즉시 자동으로 지우는** 앱.

## 동작 방식
- 알림 제목/내용에 `(광고)`, `[광고]`, `수신거부` 등 키워드가 있으면 바로 삭제
  (한국은 법적으로 광고 푸시에 `(광고)` 표기와 수신거부 안내가 의무라 대부분 걸림)
- 원하는 앱은 알림을 통째로 차단 가능
- 음악/통화 같은 진행 중 알림은 건드리지 않음
- 최근 지운 알림 기록 확인 가능

## 설치
1. `AdNotiBlocker.apk` 를 폰에서 열기 → "출처를 알 수 없는 앱 설치" 허용
2. 앱 실행 → **알림 접근 권한 허용** (설정에서 '광고알림 차단' 켜기)
3. 끝. 삼성폰은 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱을 '절전 예외'로 두면 더 안정적

## 빌드
```
ANDROID_HOME=<sdk경로> gradle assembleDebug
```
결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 한계
안드로이드는 다른 앱의 알림을 '오기 전에' 막는 API를 주지 않는다.
그래서 이 앱은 도착 순간 지우는 방식이다 (진동/소리가 아주 잠깐 날 수 있음).
완전히 안 오게 하려면 각 앱의 '마케팅 수신 동의'를 끄는 게 근본 해결책.
